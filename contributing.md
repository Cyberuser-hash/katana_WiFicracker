# Руководство по участию в разработке Katana WiFi Cracker

🎯 **Спасибо за интерес к проекту!** Любая помощь приветствуется.

## Способы участия

### 🐛 Сообщение об ошибках
- Используйте [Issue Tracker](https://github.com/Cyberuser-hash/katana_WiFicracker/issues)
- Опишите шаги для воспроизведения
- Укажите версию ОС и адаптера
- Приложите логи ошибок

### 💡 Предложение идей
- Создайте Issue с меткой `enhancement`
- Опишите предлагаемую функцию
- Объясните, почему это полезно

### 🔧 Pull Requests
1. Форкните репозиторий
2. Создайте ветку: `git checkout -b feature/название`
3. Внесите изменения
4. Проверьте код: `python3 -m py_compile katana.py`
5. Сделайте коммит: `git commit -m 'Добавлена новая функция'`
6. Отправьте в свой форк: `git push origin feature/название`
7. Создайте Pull Request

## Требования к коду
- Комментарии на русском или английском
- Проверка на наличие багов

## Тестирование
Перед отправкой проверьте:
- Работает ли на Kali Linux
- Корректно ли определяется адаптер
- Нет ли утечек памяти
